# Assets

本目录用于放置项目展示素材（GUI 截图、报告预览截图等）。

- `gui-demo.gif`: README 顶部 UI 演示 GIF（Task Config -> Task Runner -> Report Viewer）
- `gui-task.png`: GUI 的任务配置页（Task Config）截图
- `gui-runner.png`: GUI 的任务运行页（Task Runner）截图
- `report-preview.png`: GUI 的报告查看页（Report Viewer）截图

## 素材规范

- 静态截图统一使用 `1280x800` 分辨率，三张图保持同一窗口尺寸。
- GIF 推荐时长 `15-25` 秒，目标体积 `<8MB`，优先保证 GitHub 页面加载速度。
- 素材应避免包含个人隐私信息（本地用户名、绝对路径、密钥等）。
