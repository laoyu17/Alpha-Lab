# Alpha-Lab 开发计划（6-8 周）

## 里程碑

### Phase 1（第 1-2 周）

- 建立工程骨架与 CI
- 实现数据接口与 demo 数据生成
- 完成基础配置系统

### Phase 2（第 3-4 周）

- 实现算子库与因子流水线
- 完成 IC/分层收益/稳定性评估
- 接入交易成本模型

### Phase 3（第 5-6 周）

- 实现 GuardSuite（未来函数、可交易性）
- 输出报告与图表
- 增加端到端示例任务

### Phase 4（第 7-8 周）

- 完成 PyQt6 轻量 GUI
- 补齐测试与回归清单
- 完成简历展示材料（架构图、demo 截图、项目亮点）

### Phase 5（进行中）

- 落地深度学习插件接口（不破坏主流程）
- 提供可替换的内置占位插件，验证接口与评估链路
- 后续接入真实深度学习模型（如 TCN/Transformer）

## 每周节奏建议

- 周一：需求拆分和任务认领
- 周二-周四：编码 + 单元测试
- 周五：回归 + 文档更新 + Changelog

## 完成定义（DoD）

- 代码通过 `ruff`, `mypy`, `pytest`
- 核心流程能一键跑通示例任务
- 文档与 Changelog 同步更新
